# 接口与联调约定

建议按下列接口开工。A 和 B 核对后，由 A 把公共声明提交到仓库根目录的 `pdu.h`。所有长度以字节为单位。

## 公共数据与函数

```c
#include <stddef.h>
#include <stdint.h>

typedef struct {
    const uint8_t *data;
    size_t len;
} ByteView;

typedef struct {
    uint8_t src_mac[6];
    uint8_t dst_mac[6];
    uint8_t src_ip[4];
    uint8_t dst_ip[4];
    uint16_t src_port;
    uint16_t dst_port;
} PacketConfig;

typedef struct {
    ByteView udp;
    uint8_t src_ip[4];
    uint8_t dst_ip[4];
} Ipv4View;

int udp_encode(ByteView payload, const PacketConfig *config,
               uint8_t *out, size_t capacity, size_t *written);
int ipv4_encode(ByteView udp, const PacketConfig *config,
                uint8_t *out, size_t capacity, size_t *written);
int ethernet_encode(ByteView ip, const PacketConfig *config,
                    uint8_t *out, size_t capacity, size_t *written);

int ethernet_decode(ByteView frame, ByteView *ip_with_padding);
int ipv4_decode(ByteView ip_with_padding, Ipv4View *ip);
int udp_decode(const Ipv4View *ip, ByteView *payload);
```

函数成功返回 `0`，失败返回负值。编码成功时填写 `written`。解码成功时填写输出结构，输出指针指向原有缓冲区，调用方需在用完指针前保留缓冲区。各层检查长度后再读写，失败时说明原因，`main.c` 停止当前流程。封装和解封装使用同一帧的实际字节长度，缓冲区容量由调用方单独传入封装函数。

## 三次交接

| 交接 | 约定 |
| --- | --- |
| Ethernet II → IPv4 | 从 14 字节以太网首部之后开始，到 FCS 之前结束。这个范围允许包含填充。EtherType 为 `0x0800`。 |
| IPv4 → UDP | 先确认 IPv4 版本、首部长度、总长度与协议号。使用 `Total Length` 和 `IHL` 划定 UDP 范围，并把源、目的 IP 一起交给 UDP。演示生成 20 字节首部且无分片的数据报。 |
| UDP → 应用消息 | UDP 长度包含 8 字节首部。校验通过后，返回消息指针及长度。`main.c` 用 `fwrite` 按长度打印消息。 |

`wire.c` 负责多字节字段的读写和校验计算。端口、长度、IPv4 和 UDP 校验和使用网络字节序。Ethernet 采用带 4 字节 FCS 的演示格式，双方用同一个 CRC-32 函数，对首部、数据和填充计算 FCS，并以低字节在前存入帧尾。这个格式从目的 MAC 字段开始。

UDP 校验和覆盖 IPv4 伪首部、UDP 首部和数据。发送端把算出的 `0x0000` 写成 `0xFFFF`，奇数长度时参与求和的补零字节只用于计算。UDP 和 IPv4 的封装从同一份 `PacketConfig` 读取 IP 地址。解析时使用 IPv4 首部实际读到的地址验证 UDP 校验和。

## 联调用例

| 用例 | 测试输入 | 预期表现 |
| --- | --- | --- |
| 短消息 | `Hello, UDP!`，11 字节 | UDP 19 字节，IPv4 39 字节，帧 64 字节，其中填充 7 字节。三层校验通过，原文还原。 |
| 无填充 | 32 字节 ASCII 消息 | UDP 40 字节，IPv4 60 字节，帧 78 字节。三层校验通过，原文还原。 |
| FCS 错误 | 正常帧中任取一个数据字节翻转一位，保留原 FCS | 以太网层报告 FCS 校验失败。 |
| 截短首部 | 对要测试的解码函数直接传入比首部短的输入 | 对应层报告长度不足。 |

正常用例由 `main.c` 打印完整帧十六进制和各层字段。报告以实际运行结果为准。
